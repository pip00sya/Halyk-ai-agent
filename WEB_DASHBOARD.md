# Halyk AI Command Center

Локальная web-панель объединяет управление агентом, просмотр результатов и проектную
документацию. Она запускается на `127.0.0.1` и по умолчанию недоступна другим устройствам
в сети.

## Запуск

```powershell
.\run_dashboard.ps1
```

Или напрямую:

```powershell
python dashboard_server.py
```

Адрес по умолчанию: `http://127.0.0.1:8765`.

## Что доступно в интерфейсе

- запуск режимов `auto`, `public` и `llm`;
- быстрые профили Public/Private, которые синхронно выбирают папку и безопасный маршрут;
- выбор папки с датасетом, команды, email, модели и reasoning effort;
- dataset intelligence: сценарии, ячейки, операции, PDF, страницы, OCR и выявленные риски;
- объяснение пятиступенчатой evidence-first архитектуры и состава финальной отправки;
- независимый второй LLM-проход для private-режима;
- текущий статус, время и технический журнал запуска;
- проверка структуры `submission.json` и ссылок на транзакции;
- таблица 36 решений с фильтрацией и поиском;
- drawer с порогом, actual, evidence, rationale, фактами и документами-источниками;
- скачивание `submission.json` и `decision_trace.json`;
- чтение основных Markdown-документов проекта.

## Локальный API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/status` | Готовность датасета, интеграций, отчёт и public score |
| `GET` | `/api/run` | Состояние текущего запуска |
| `POST` | `/api/run` | Запуск агента в фоновом процессе |
| `POST` | `/api/preflight` | Проверка архива, маршрута, OCR, модели и метаданных без создания ответов |
| `POST` | `/api/validate` | Валидация текущего submission |
| `GET` | `/api/results` | Решения, summary и decision trace |
| `GET` | `/api/document?id=...` | Безопасное чтение разрешённого Markdown-файла |
| `GET` | `/api/download/submission` | Скачивание файла для сдачи |
| `GET` | `/api/download/trace` | Скачивание технического следа |

## Безопасность

- `OPENAI_API_KEY` не возвращается API и не попадает в браузер;
- интерфейс показывает только готовность LLM-режима, без передачи значения ключа;
- журналы дополнительно очищаются от значений известных переменных с ключами;
- сервер принимает команды списком аргументов без shell-интерполяции;
- локальные документы читаются только через фиксированный allowlist;
- POST-запрос ограничен 64 КБ;
- кнопка запуска блокируется на время выполнения, что исключает двойной запуск.

## Дизайн и доступность

Источник правил: `design-system/halyk-ai-workspace/MASTER.md`, фирменное переопределение:
`design-system/halyk-ai-workspace/pages/dashboard.md`.

Интерфейс использует семантические элементы, видимый focus, skip link, SVG-иконки,
текстовые подписи статусов, touch targets от 44 px и `prefers-reduced-motion`. Финальная
визуальная проверка выполнена при ширине 375 и 1280 px: горизонтального переполнения и
ошибок в консоли нет.

## Честное ограничение

Public score `36/36` относится к калиброванному fact pack с проверкой SHA-256. Он полезен
для проверки формата, расчётов и интерфейса, но не доказывает точность LLM-planner на
приватном датасете. Структурный preflight локального private-архива пройден; перед финальной
сдачей semantic pipeline всё равно нужно прогнать с настоящим `OPENAI_API_KEY`.
